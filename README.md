# Real-Time Chat Application (Spring Boot + Spring AI + WebSocket)

This project is a **real-time chat application** built to learn and implement **WebSocket communication** using **Spring Boot** and **STOMP**, with **Spring AI integration** for AI-powered responses.

The application enables multiple users to chat instantly without page refresh and also supports **AI-based message handling**.

---

##  Tech Stack

- Java
- Spring Boot
- Spring WebSocket (STOMP)
- Spring AI
- Spring Security (optional)
- HTML, CSS, JavaScript
- Bootstrap
- Maven

---

##  Features

- Real-time messaging using WebSockets
- STOMP protocol for message handling
- Broadcast and private messaging
- AI-generated responses using Spring AI
- Lightweight frontend (HTML + JS)
- No page refresh required
- Scalable and event-driven architecture

---

##  How Real-Time Chat Works

1. Client connects to WebSocket endpoint
2. STOMP establishes a persistent connection
3. User sends a message
4. Server processes and broadcasts the message
5. Other connected users receive it instantly
6. Optional: message is processed by Spring AI for AI response
